# Что готовим?

Демо на Next.js App Router с двенадцатью примерами рецептов и иллюстрациями этапов приготовления, созданными ИИ. Можно выбрать несколько продуктов кнопками или ввести через запятую. Поиск показывает блюда хотя бы с одним совпадением, сортирует по числу совпадений; избранное сохраняется в браузере через localStorage. Данные лежат в `lib/recipes.js`.

## Запуск

Нужен Node.js 20.9 или новее.

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Маршруты

- `/` — главная
- `/recipes` — все рецепты
- `/recipes?ingredients=яйца,томаты` — поиск
- `/recipes/[slug]` — страница рецепта
- `/favorites` — избранное

Для production: `npm run build`, затем `npm start`. Демо не использует базу данных, авторизацию или внешний API; поиск — простой по совпадениям названий.

Интерфейс и рецепты доступны на русском, узбекском и английском языках. Выбранный язык сохраняется в браузере. Поиск понимает основные названия продуктов на всех трёх языках.
